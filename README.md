## Conferência das respostas

Cada pasta tem um arquivo `verificacao.py` que refaz em Python as contas das questões e confirma as respostas. Os scripts usam só a biblioteca padrão do Python:

```bash
python aula-02-exercicios/verificacao.py
python lista-conjuntos/verificacao.py
python lista-funcoes/verificacao.py
python revisao-avp1/verificacao.py
```
